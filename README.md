Hi, I’m Adam, a PhD student at **Warsaw University of Technology** working on mathematical statistics.

My research is primarily theoretical, but I want the methods I study to be useful in practice. I develop open-source software to make them easier to explore and apply, with particular attention to usability.

Some of the projects I contribute to:

- **[gips](https://github.com/PrzeChoj/gips)** — discovering permutation symmetries in Gaussian data and using them to improve covariance estimation.
- **[gipsDA](https://github.com/AntoniKingston/gipsDA)** — bringing permutation symmetry into linear and quadratic discriminant analysis.
- **[pcglassoFast](https://github.com/PrzeChoj/pcglassoFast)** — fast Partial Correlation Graphical LASSO for estimating sparse Gaussian graphical models.
